## 2. Whole historical files replaced outright

These files' hardware/DOS plumbing is fully superseded by a hand-written
portable subsystem (tu-porting-rules.md sec 5); grep across `src/*.C`
confirms none of their functions is called from any file outside itself,
so none needs a `game_funcs.h` prototype -- they are never going to be
mechanically ported.

- **src/CRITERR.C** -> dosio.h -- tu-porting-rules.md sec 4: harderr/hardresume/hardretn call sites are deleted and the read-vs-write failure policy is routed through dosio.h instead
  - functions dropped: `dos_critical_error_handler`, `dos_critical_error_install`
- **src/LIB_RAND.C** -> portable/compat/cclib.c -- this IS the historical Turbo C rand/srand LCG this script's sibling cclib.c reimplements byte-for-byte (state=state*0x015A4E35+1; return (state>>16)&0x7fff); keeping both defined would collide with cclib.h's `#define rand cc_rand`
  - functions dropped: `rand`, `srand`
- **src/RESOURCE.C** -> portable/resource (resource.h + decode.h) -- resource_load_record's whole flag/type dispatch, including its private helpers sprite_sheet_decode_sequential/sprite_sheet_decode_indexed and the DECODE.ASM calls they make, is reimplemented by resource_load_record() per resource.h's own header comment; grep confirms no src/*.C file outside RESOURCE.C calls any of its functions
  - functions dropped: `disk_reset_retry`, `resource_file_open`, `resource_file_write_record`, `resource_load_record`, `resource_load_record_alloc`, `resource_load_record_into`, `sprite_sheet_decode_indexed`, `sprite_sheet_decode_sequential`
- **src/STARTUP.C** -> portable/game/startup.c (supervisor-written) -- tu-porting-rules.md sec 5 row 3: cmdline_parse_args/bios_equipment_probe/video_adapter_detect/sound_backend_probe/video_mode_select are explicitly replaced; dos_write_handle2 has no caller outside RESOURCE.C (also wholesale-replaced) and STARTUP.C itself, so it is retired with the rest of the file (its fputs(text,stderr) semantics, minus the trailing byte, are documented in tu-porting-rules.md sec 4 for whoever writes startup.c)
  - functions dropped: `bios_equipment_probe`, `cmdline_parse_args`, `dos_write_handle2`, `sound_backend_probe`, `video_adapter_detect`, `video_mode_select`
- **src/VIDEO.C** -> portable/gfx (gfx.h) -- every VIDEO.C function is either a gfx.h primitive already, or one of video_alloc_framebuffer/video_set_text_mode/video_normalize_far_ptr, replaced by gfx_framebuffer_init()/portable/game/startup.c per tu-porting-rules.md sec 5
  - functions dropped: `color_lookup_tables_init`, `color_table_entry_set`, `cur_color_index_get`, `gfx_color_select`, `rect_border_draw`, `video_alloc_framebuffer`, `video_load_palette`, `video_normalize_far_ptr`, `video_set_text_mode`
