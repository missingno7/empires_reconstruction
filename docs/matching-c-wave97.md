# Matching C wave 97

This wave originally established four complete return-terminated matching-C proofs. The remaining canonical C owners are
`F_28AC` (218), `F_D61C` (384), and `F_D79C` (123). `F_25B3` was later superseded by a symbolic TASM recovery; see [its receipt](f25b3-symbolic-asm.md).
These remaining explicit instruction-byte sources compile with no external fixups or
loader relocations. Exact EXE and DAT equality remains proven, with 21,685
executable bytes still raw.
