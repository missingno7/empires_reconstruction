# B4374 board-control BSS block

The 64-byte BSS span beginning at `_b4374` is now emitted as named typed
storage by `B4374_CONTROL_STATE_BSS`. This preserves its existing canonical
public anchors while replacing the anonymous reserve with the following
evidenced layout:

| Offset | Storage | Evidence |
|---:|---|---|
| `00` | three one-byte board-control fields | `F_4713` reads `_b4374` as flags and uses `_b4375`/`_b4376` as coordinate inputs. |
| `03` | `b4377_selection[3]` | `F_2AE2` reads its selected board id, column, and row. |
| `06` | six slot ids, columns, and rows | `F_2AE2` and `F_3A75` index `_b437a`, `_b4380`, and `_b4386` with the six visible slots. |
| `18` | four ten-byte neighbour tables | `F_3A75` follows `_b438c`, `_b4396`, `_b43a0`, and `_b43aa` as directional transitions indexed by the current board id. |

The names describe observed access roles rather than claiming recovered
historical identifiers. `python tools/probe_source_data_link.py` assembles the
new BSS object and verifies every public offset and the whole structural link.
